## 更新内容

### 新增

- **移动端与局域网访问**：手机浏览器可直接打开使用（侧栏抽屉化、聊天单列、触屏适配，Electron 与桌面浏览器完全不受影响）；设置里可开启局域网访问，其他设备扫码即可打开 Web 端（内置 SPA 托管、访问地址二维码、SSH 隧道指引），并新增修改密码的强度校验
- **后台任务统一为 job 四动词**：`job_read` / `job_list` / `job_stop` / `job_send` 覆盖本地 shell、远程作业、子 Agent、Workflow 与定时任务；后台输出合并为单份日志，Windows 用 Job Object 托管整个进程树，完成通知统一以时间卡片进入对话流
- **浏览器工具改为脚本化 `browser_run`**：一个脚本驱动整套浏览器动作，Playwright 风格 locator 在动作时实时解析，带可操作性探测、trusted 输入、自动滚动重试与四态等待；旧 `browser_*` 工具退役
- **压缩降级与 `/compact` 命令**：摘要输入超限时分级剥离（工具结果 → 思考 → 图片 → 文件）并按轮丢弃最旧内容，切换到更小窗口时会提示；新增 `/compact`、`/compress` 本地命令（可附加指令，命令本身不进入模型）
- **输入队列改为后端权威**：忙碌时的排队、暂停/继续、排序、立即发送、失败保留全部由服务端维护，刷新与多窗口看到同一份队列
- **工具图片内嵌 tool-result**：工具产出的图片直接写进对应 tool-result，归属可追溯；多模态模型自动派生图片消息，纯文本模型投影为占位说明
- **Web 端目录浏览器**：Web 模式下新建项目、选择工作目录、知识库根目录、附件子目录都使用内置目录浏览器（Electron 仍用原生选择框）
- **技能市场升级到官网市场 API v2**：按界面语言推荐技能，支持搜索与分类过滤
- **搜索新增 AgentHome 供应商**：通过 MCP 上游调用 web_search / web_fetch
- **`/workflow` 斜杠命令**：输入 `/` 选择「工作流」，或直接 `/workflow <任务>`，按会话可用性给出引导

### 优化

- 输入区配置修改立即生效（按会话合并保存、发送前 flush）；移除全局默认对话模型，改为按「会话模型 → 智能体模型」解析，全部缺失时明确报错
- 消息操作条与 Token 用量合并为一行，界面更紧凑
- 插件 / Skills / MCP 页面分区重构，技能展示名识别私有字段
- 首次启动引导仅在 Electron 自动弹出（Web 端不再弹）

### 修复

- 修复大工作区下 Git 状态与文件监听无界导致的渲染进程 OOM（git status 加 512KB / 15s 上限、变更列表虚拟化、watcher 加过滤与降级、目录树分页）
- 修复从设置页返回时固定跳到新建会话的问题（改为回到进入设置前的页面）
- 修复会话切换时 mainSession 派生 computed 的初始化顺序问题

### 说明

- 1.0.7 的 Windows 用户可直接在应用内更新到 1.0.8（差量更新，只下载变化的块）；更早版本仍需手动安装
- macOS 暂不支持应用内安装（未公证），继续从官网下载页手动安装
- 旧 `browser_*` 工具已退役：会话里的历史调用仍可回放，新请求请使用 `browser_run`
