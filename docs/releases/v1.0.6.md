## 更新内容

### 新增

- **Windows 应用内下载并安装更新**：发现新版本后直接在应用内下载（实时进度与速度、支持取消与后台下载），校验 SHA-512 后打开安装向导，装完自动重启；标题栏与「设置 → 关于」同步显示版本状态
- **Windows 增量更新基础**：1.0.6 起安装包携带 `.blockmap` 并缓存本次安装包；从下一个版本开始，应用内更新只下载发生变化的块（实测仅版本号变化约 1.2 MB / 0.7%），差量不可用时自动回退整包
- **Token 用量统计**：设置页新增「用量统计」面板 —— 近一年热力图、每日与每月模型趋势、模型/来源/会话排行，支持清空统计和历史数据回填
- **WSL 发行版作为附加工作目录**：远程工作区新增第三种连接类型，可直接挂载本机 WSL 发行版（复用 stdio 传输，远端 agent 端零改动）
- **审批卡「本轮内自动放行」**：在一张审批卡上选择后，本回合后续命令、敏感路径、越界写入的审批直接放行；下一条用户消息开新回合时自动失效（计划审批与提问不参与）

### 优化

- 统一弹窗体系：所有弹窗迁到 GdDialog，补齐焦点陷阱、ESC 关闭、滚动锁与层级管理，尺寸收敛为固定档位
- 输入框变窄时只保留必要工具栏按钮；侧栏分组折叠后主动丢弃「加载更多」拉出的会话，避免误点
- 上下文占用指示器改为每次 LLM 请求后即时刷新，长工具执行期间也能反映真实占用
- 计划模式提醒按周期落库，被压缩遮蔽后自动补注入，退出说明持久化
- 远程工作区在会话与输入区增加连接类型标识

### 修复

- 修复会话切换时浏览器标签选中态丢失、文件预览串会话的问题（后端文件接口错误码同时区分为 400/403/404/413）
- 修复流式中点「回到底部」落不到真正底部的问题
- 修复大纲远距离跳转被贴底撤销、刚滚上去又被拉回底部的问题
- 修复 SSE 长连接被计入请求耗时导致日志刷屏；MCP 服务器超时改为按服务器配置生效

### 说明

- 检查更新仍走官网 `check_update`（1.0.6 起返回按平台分组的 `downloads` 字段），安装包直链走 GitCode
- macOS 暂不支持应用内安装（未公证），继续从官网下载页手动安装
- **本次升级仍需手动安装一次**；从下一个版本起，Windows 可在应用内直接完成更新
- 发布页会保留各版本的 `.blockmap`，这是跨版本差量更新的基线，请勿删除
