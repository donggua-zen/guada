## 更新内容

### 新增

- **桌面宠物**：新增可开关的常驻桌宠窗（取代旧「托盘悬浮任务状态卡」），支持多会话气泡列表、跟随工作状态的情绪动画、透明度/尺寸/播放倍速设置；兼容自有逐帧与 Codex 图集（pet.json + spritesheet）双格式，自动扫描 `~/.petdex` / `~/.codex` 宠物目录，并提供内置形象切换、Codex 图集导入与形象卸载
- **在线插件市场与宠物市场**：插件页新增「市场」视图（官网索引 + git 托管分发，搜索、标签、分页、详情、带进度的安装，安装源协议白名单）；安装框自动识别仓库网页地址、clone 地址、`owner/repo` 短写法、`file://` 与本地路径；设置页新增「宠物市场」（索引、缩略图、一键安装，直接下载精灵图，不依赖 Node/npx）
- **插件 API v3/v4 运行时**：新增自定义 HTTP 路由、宿主模型调用（complete/stream/listModels）、后台作业、Hook、命名提示词段与装配变换、插件数据目录、配置 Schema 表单；前端新增可完整卸载还原的主题/皮肤运行时、全页工作台与对话侧栏页槽、插件通用配置页
- **插件专属智能体与能力包**：插件可注册虚拟智能体（能力作用域、部分字段可编辑、子代理白名单与 hidden 角色），工具包升级为能力包（注册技能并随全局启停/角色裁剪/加载模式同步显隐），插件详情弹窗完整展示各类贡献
- **主题**：新增内置主题「柒·义体夜航」与外置皮肤「柒·残月都市」（亮暗通用、壳层透明度分档），移动端不再套用桌面预设主题，回桌面时自动恢复；外置皮肤后续改为独立插件分发
- **会话目标自动推进**：`/goal` 支持设置、暂停、恢复、清除目标，输入区状态胶囊显示阶段、迭代数与用量，独立 verifier 判定推进，状态以 JSONL 事件溯源落盘（不改数据库）
- **压缩失败可见化**：上下文压缩失败按限流、网络、超时、请求拒绝分类落库，并在对话流以事件卡展示原因（刷新后仍在，历史消息保持不变）
- **WorkBuddy 会话导入**：历史会话导入新增第五来源，双根扫描 `~/.workbuddy` / `~/.workbuddy-ai`，提取真实提问、配对工具调用结果、去重编辑重发与映射用量
- **知识库文件预览**：预览弹窗改为默认「原文预览」（PDF 走 Chromium 原生渲染，图片、Markdown、文本分类型展示，含 206 Range 与中文文件名），「分块」作为调参核对第二入口并支持复制、检索结果直达命中块
- **Computer Use 工具升级**：`computer_observe` 拆为独立工具（截图/光标/窗口/应用/等待）并返回 generation，`computer_input` 新增 set_value、drag、click_element 且强制 `expected_generation` 校验，避免基于过期屏幕坐标误操作
- **浏览器标签预算与清理提醒**：每个来源最多 8 个 AI 标签（6 个起提醒、超限返回 `TAB_LIMIT`），新建/关闭结果附带标签摘要、失效标签自动接管、脚本结束列出残留标签
- **任务栏未读角标**：审批/询问到达且窗口隐藏或非当前会话时显示红点（Windows overlay 图标 / macOS Dock badge），进入会话或窗口恢复即清除
- **Shell 后端选择**：新增 `system.shellBackend` 设置（auto / Git Bash / PowerShell / cmd），run_command 与交互终端共用，Windows 按可用性置灰未安装项（默认 auto 行为同旧版，重启生效）
- **对话与统计细节**：会话「…」菜单新增宽窄对话模式切换（744↔1138px、偏好持久化，消息列/输入框/预览联动），用量统计新增「今日」维度

### 优化

- 拖拽分割条/缩放窗口的性能优化：调整期跳过视口外回合绘制、冻结回合高度、合并 rAF 与防抖（300 回合拖拽约 32fps → 60fps），并消除按压不动时的内容塌陷、挤压聊天区时滚动条跳动
- 流式 Markdown 渲染改为顶层块级缓存 + 150ms 节流（leading 立即、trailing 必达），只重渲尾部变化块，静态文档仍即时渲染
- 工具行文件参数改为「扩展名图标 + 文件名 + 淡色目录」三段式，长路径不再挤出文件名；输入框默认高度提至 110px，消除首次输入顶跳
- `job_read` 改为按游标增量读取，未读超上限时只保留最新 64KB 并告知跳过量与完整日志路径，无新输出给明确提示
- 计划模式优先委派只读调研子代理（提醒强化广搜/并行语义，子代理继承计划模式与只读沙箱）
- 流式生成中允许按已完成回合分支（移除会话级 409 拦截，仅未完成的在途回合仍不可分支）

### 修复

- 修复 LLM 流中途空闲超时被 SDK 吞成正常结束、半截消息（含 tool-call）按成功落库；现在统一抛超时错误并走既有重试/告警链路（覆盖 openai / openai-response / anthropic / gemini 适配器）
- 修复图片预览常驻挂载吞掉全局左右方向键，导致会话内输入框光标无法用方向键移动
- 修复发送失败（网络/4xx/5xx、模型缺失、本地命令被拒）时正文与附件被提前清空；改为服务端确认成功后才清空并聚焦，等待期间按钮显示 loading 且防重复发送
- 修复思考模型生成提交信息时固定 300 token 预算被思维链耗尽、正文为空误报「生成失败」；移除固定上限，输出截断单独返回 `output_truncated` 并给出中英文提示
- 修复右侧工作区 Markdown 预览在文件被外部修改/刷新后滚动位置跳回顶部（按路径记忆并按新旧文档高度比例还原）
- 修复侧栏目录模式新建会话先落「通用」需刷新才归组，以及「通用」桶「+」误落到上次工作目录的问题
- 修复内置主题与深色主题的一批对比度/配色问题（winxp / e-ink / y2k / famicom 接通 token 链、选中行白底白字、用户菜单写死灰、主题 CSS 异步加载后标题栏配色未重算）
- 修复模型编辑页复选框点不动、智能体头像控件贴卡片右缘、运行模式弹层图标变形，以及 Windows 下对话标题栏重复充当窗口拖拽区
- 修复远程工作区连接重名只报 500 且无字段提示，改为名称框字段级提示 + HTTP 409 并回跳聚焦
- 修复 Windows 打包版退出兜底 `taskkill` 缺 `windowsHide` 闪黑色控制台窗口，以及 Electron 脚本异常弹窗阻塞、console 断管后 EPIPE 自激循环刷满日志
- 修复 Electron 打包校验：better-sqlite3 若被换回系统 Node ABI 的预编译包，构建时立即检测并重新拉取 Electron 版本，避免本地打包版启动即崩

### 说明

- 桌宠为独立设置项且**默认关闭**，旧版「托盘悬浮窗」的开关/透明度设置会自动迁移；旧的托盘悬浮状态卡不再提供
- 移除消息「编辑内容」就地编辑入口（链路已失效、后续重新设计）；「编辑后重发」、排队消息编辑与 `message/prune` 回放保留
- 插件 manifest 新增 `apiVersion` 门控，宿主最高 v4；未声明的旧插件按 v1 照常加载，声明值高于 v4 的插件会提示升级 GuaDa；安装目录统一按 `manifest.id` 命名，旧目录在更新时自动归位
- 浏览器自动化新增标签预算后，一次运行中打开过多标签的既有脚本会收到 `TAB_LIMIT`，需按提示关闭/接管标签
- 1.0.10 的 Windows 用户可直接在应用内更新到 1.0.11（差量更新，只下载变化的块）；更早版本仍需手动安装
- macOS 暂不支持应用内安装（未公证），继续从官网下载页手动安装
