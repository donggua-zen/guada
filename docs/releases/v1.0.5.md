## 更新内容

### 新增

- 远程工作区支持 **Docker 容器**：把运行中的容器（devcontainer / docker compose 起的服务）挂成附加工作目录，工具直接读写容器内目录；GuaDa 只附着，不创建、停止或删除容器
- 远程工作区 **SSH 链路改走 stdio 传输**：不再要求远端 sshd 开放端口转发（AllowTcpForwarding），硬化环境与容器里的 sshd 也能连；远端 agent ≥ 0.6.0 自动启用，旧版回退原链路
- 工作区全屏时对话改为**可拖拽悬浮面板**：全屏看代码或预览时，对话变成可拖动、可缩放的浮窗，流式输出与草稿不中断
- **会话滚动记忆与底部锚定**：切走再回来能回到上次的滚动位置；流式输出自动贴底，手动上滑后不再被拽回
- 输入区新增**独立的远程目录入口**，新建会话对话框共用同一套交互

### 优化

- 悬浮对话面板：默认 430px 宽、四边四角可缩放、尺寸与位置持久化，窄窗口下不再被推出屏幕；面板内输入区收掉多余边距，留给消息的空间更多
- README 新增「远程工作区」专章（SSH 与 Docker 两个场景，中英双语），补传输矩阵与性能实测

### 修复

- 修复思考模式下 `deepseek-flash` / `deepseek-pro`（官方 2026-09 改名）历史轮次 reasoning 被剥离的问题
- 修复悬浮对话面板隐藏后按钮残影滞留约 0.2 秒的问题
