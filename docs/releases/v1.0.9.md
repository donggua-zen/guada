## 更新内容

### 新增

- **机器人会话工作台**：机器人 / 外部用户的会话聚合到一个工作台，统一侧栏与会话菜单，标题栏展示会话信息；机器人状态经全局 SSE 实时同步，页面自动刷新并记住上次选中的会话（旧的机器人管理页与会话弹窗已移除）
- **机器人管理员与安全模式**：每个机器人可配置管理员列表，未配置时一律按非管理员处理；非管理员回合只放行白名单工具（网页搜索、知识库只读、MCP 等），管理员保留完整能力。会话行菜单可一键设为 / 取消管理员，标题栏显示管理员徽标或安全模式提示；企业微信群聊与 QQ 群的成员身份解析一并修正
- **机器人二维码入口**：微信个人号卡片常显二维码按钮，登录中会高亮提示
- **浏览器自适应视口**：预览工具栏与设置中心支持「自适应」，视口跟随预览面板实时重排；人类手动打开的网页默认自适应，AI 也可通过 `browser_run` 的 `tab.setViewportSize()` 指定视口（320–3840 × 240–2160）
- **周期性待办提醒**：距离上次待办调用与上次提醒都达到 10 个助手轮次时注入一次隐藏提醒，只在该会话有未完成待办时生效
- **`edit` 工具强化**：新增整体替换（replace_all）；遇到多处匹配而未指定时报错并提示扩大上下文；自动剥离 `read` 输出里的行号前缀；改为字面替换，不再把 `$&` 之类当成替换语法
- **移动端连接自愈**：锁屏或切后台导致连接半开时，回到前台主动重建；息屏期间跑完的回合会补拉终态，界面不再永远停在「流式中」
- **`job` 工具语义收敛**：`job_read` 的 `wait` + `timeout_ms` 合并为 `wait_ms`（缺省不阻塞、上限 10 分钟），`job_send` 改为原样透传（字节流漏写换行时回执给出提示）

### 优化

- Windows 取消「只读」会话档位（只保留工作区可写 / 自由编辑，历史只读会话自动归一化），macOS / Linux 三档不变
- 存储层移除 Prisma 与数据库→文件迁移脚手架，运行时完全由 better-sqlite3 直接读写
- 会话打开与渲染增加性能追踪（路由切换 / 详情拉取 / Markdown 解析等分段埋点）
- 侧栏分组展开状态独立管理，切换会话后不再丢失

### 修复

- 修复上游把 `max_tokens` 计入共享总窗口导致 400 的问题：输出预算按剩余窗口收缩，压缩决策改用「总窗口 − 输出预留」的有效窗口，用量指示器同步展示口径说明
- 修复重开侧边栏时目标标签被恢复的选中态覆盖
- 修复窄容器下模型按钮被隐藏（保留按钮并截断模型名）
- 修复插件 / Skills / MCP 列表在移动端横向溢出、文案不换行
- 修复技能市场的版本升级判断

### 说明

- 1.0.8 的 Windows 用户可直接在应用内更新到 1.0.9（差量更新，只下载变化的块）；更早版本仍需手动安装
- macOS 暂不支持应用内安装（未公证），继续从官网下载页手动安装
