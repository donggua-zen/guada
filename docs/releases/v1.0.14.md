## 更新内容

### 新增

- **项目级技能开关**：技能管理页新增项目下拉，按侧栏「目录」分组展示可用技能；全局与项目统一使用 `skills.yaml` 覆盖表（`skills: { 技能id: true/false }`），项目可单独关闭技能，也可以显式启用全局已关闭的技能，键不存在则继承上层
- **Markdown 正文图片按会话工作目录解析**：相对路径改走会话工作区取图端点（带越界检查），连续纯图片段落自动合成画廊（按比例并排、超宽换行、窄屏单列），单图最多半宽、长图按最大高度收窄、小图保持原尺寸，并支持点击大图预览
- **断流续写**：无任何工具调用、正文 ≥800 字符且错误可重试时，断流不再丢弃正文重新开始，而是保留已生成内容继续写，降低不稳定模型的长文成本
- **知识库配置引导**：知识库页新增配置状态面板与模型/OCR 快捷设置入口，未完成配置时可直接跳转补齐
- **本地路径链接**：Markdown 中的本机绝对路径（盘符、反斜杠、UNC、`file://`、POSIX）可直接预览或用系统默认程序打开，工作区内外统一走本地文件打开链路
- **侧栏分组收敛**：每组会话数按分组规模自适应（≤3 组 10 条、4–6 组 7 条、≥7 组 5 条），首屏、「加载更多」步长与折叠回收统一档位，项目多时不再把侧栏撑满

### 优化

- 插件「刷新」改为真正重扫插件目录：新增/变更/删除同步，按 mtime+size 指纹跳过未变化项，并发刷新串行化，单插件失败不影响其他插件
- 子代理 handoff 不再误判失败：成败按末轮裁决，正常让位记为 completed，失败原因不再显示派发 ACK 文本
- 回合中段事件卡（压缩/上下文提示/截图裁剪/后台作业完成通知）按消息顺序原位渲染，不再固定堆在助手消息顶部
- 输入框草稿在编辑器更新时直接同步，避免发送或切换会话时草稿丢失
- 侧栏设置图标改为线框风格；插件详情弹窗层级与安装交互修复，SkillHub 安装图标保留
- 新增 PluginApi v4 权威文档（`docs/plugin-api.md`）与契约防漂移测试，插件 `entries`、嵌套 schema、命令启停三处契约缺陷修复

### 修复

- 修复上游空闲超时被误判为用户中止、两层重试被短路的问题；有可见输出时按恢复策略处理
- 修复流式内容偶发缺失与思考态残留
- 修复子代理 handoff 被记成失败、整行转红
- 修复插件 `manifest.entries` 不生效、顶层 `registerTool` 丢失嵌套 schema、命令启停异常
- 修复插件目录仅在启动时扫描一次，手工放入的插件刷新后仍看不到
- 修复回合中段事件卡位置错误
- 修复 Markdown 相对图片按运行目录解析导致裂图/串图
- 修复弹窗层级与安装交互问题

### 说明

- 技能配置统一为 `skills.yaml` 覆盖表：全局 `<SETTINGS_DIR>/skills.yaml`、项目 `<项目>/.guada/skills.yaml`；`skills: { id: true/false }`，键不存在继承上层，项目可覆盖全局
- Windows 用户可直接在应用内更新（差量）；macOS 1.0.13 起支持应用内更新，1.0.12 及更早仍需从官网手动安装一次
- 官网下载页与 GitCode 镜像同步更新
