## 更新内容

### 新增

- **历史会话导入**：支持从 Claude Code、ZCode、DSH、Codex 迁移历史会话 —— 自动扫描本机数据、按时间/工作区筛选、按工作区分组多选导入；保留原始时间戳与上下文占用锚点，压缩会话合成完整的三事件（界面全量可见），重复导入幂等跳过
- **去 Element Plus 收官**：全部 UI 控件迁移到自研 Gd 组件（Tabs / Pagination / Collapse / ImageViewer / Drawer / DatePicker / TimePicker / Tree 等），element-plus 整包卸载；顺带修复一批组件层缺陷（下拉"无数据"、滑块不跟手、开关无效、弹窗滚动等）
- **供应商体系插件化（Provider Pack）**：外部供应商可通过安装插件包接入，无需改应用代码；协议下拉/标签/图标全部接口驱动；新增 Ollama 原生协议示例包。行为变更：未知协议不再静默回退 openai，改为明确报错
- **请求体 gzip 压缩**：≥64KB 的 JSON 请求体自动压缩（任何协议可用，供应商卡片或实例声明 `requestCompression` 即可），编码被拒自动明文重发；实测 288KB 请求压到 1.7KB
- **SkillHub 技能市场**：技能页新增第三个视图，经后端代理安装并记录来源
- **MCP 启动失败可读化**：spawn 失败按原因分类、回落到内置 Node 运行，测试连接透出真实错误
- **浏览器能力补齐**：接管原生弹窗（alert/confirm 交给模型处理）、下载自动落盘并登记、`window.open` 统一开内部标签、权限策略 fail-closed；locator 补齐 Playwright 基础读取与轻量动作（isEnabled / getAttribute / dblclick / focus / clear 等）、支持链式作用域
- **工具包学习入口迁移至 skill_learn**：懒加载工具包以"动态工具技能"形式进入技能体系（`tool_learn` 退役，`tool_use` 不变）
- **其他**：默认模型设置改为可搜索下拉（供应商名作分组头）；Windows 取消只读档位后的能力端点 `/capabilities`；媒体预算提升至 24MiB；新内置浅色主题「喜鹊」

### 优化

- 请求体压缩说明改为「仅少数供应商支持，一般不勾选」，供应商编辑卡片直接暴露开关；压缩已通用化，移除 Guada Relay 专用供应商包
- 旧分组展开卡顿优化：折叠内容退出布局、展开动画减半
- 消息导航条交互对齐 ZCode（含键盘导航与定位反馈）
- 截图作为会话附件返回（支持 saveTo 显式导出），工具截图按预算裁剪
- 浏览器：明确标签语义（无标签时提示 `tab.goto(url)` / `newTab`）、脚本内可用 setTimeout/setInterval 且随取消清理、快照回归纯观察

### 修复

- 修复图片预览关闭钮与 Windows 原生窗口按钮重叠
- 修复插件页一级 tab 切换后二级视图串台
- 修复设置页热力图横向滚动条与月份标签重叠
- 修复目录模式新建会话的扩窗 key 与目录桶不一致
- 修复表单已填内容仍报「请输入…」（useFormValidation 取值 getter）
- 修复侧栏目录模式下新建会话行为；修复隐藏 webview 吞点击、失焦/遮挡时截图超时
- 修复技能创建后不自动注册；修复设置页重挂载时主题被启动期快照回滚
- 修复工具分组标题悬空逗号与空聚合文案；取消图片工具结果默认展开

### 说明

- 1.0.9 的 Windows 用户可直接在应用内更新到 1.0.10（差量更新，只下载变化的块）；更早版本仍需手动安装
- macOS 暂不支持应用内安装（未公证），继续从官网下载页手动安装
