## 更新内容

### 新增

- **Windows 桌面 Computer Use**：新增独立 sidecar（GDI 截图、UIA 树、SendInput 输入），智能体可直接操作 Windows 桌面；带观察租约、动作策略与审批卡，**默认关闭**，需在设置页手动开启
- **侧栏按工作目录分组（项目模式）**：侧栏可在「分组 / 目录」之间切换，目录模式按工作目录自动分桶，支持拖拽排序、重命名、归档与删除项目；分组与项目支持自定义 Fluent 图标（23 个语义图标）
- **概览区新增当前智能体卡片**：概览顶部常驻智能体头像、名称与描述，随会话/智能体切换自动更新
- **浏览器预览支持释放指针锁**：Esc 或 Ctrl+Alt+R 可释放 Pointer Lock、HTML 全屏与键盘锁，切换或关闭标签时自动释放
- **上下文占用持久化**：每次 LLM 请求与工具结果后落盘，中断或冷启动后能恢复小轮次上下文占用，异常终止的回合也可继续作为锚点

### 优化

- 插件页改为紧凑卡片列表，支持主题自适应
- 侧栏分组与项目的操作统一为 hover 省略号菜单；新建会话、新建项目、展开/收起按钮改为 hover 显示，侧栏更清爽

### 修复

- 修复 LLM 连接阶段 10 秒超时被误判的问题（undici 默认 connectTimeout 早于应用层超时，表现为对话中途突然 "Request timed out."）；连接类错误归一化并进入重试
- 修复企微流式回复逐 token 等待 ack 造成积压：增量按 150ms 合并，会话准备或启动失败时会把错误原因回传给 IM 用户
- 修复窄容器下「回到底部」按钮越界、出现横向滚动条的问题（状态行两侧预留 36px）

### 说明

- 1.0.6 的 Windows 用户可直接在应用内更新到 1.0.7 —— 这是差量更新首次真正生效（只下载发生变化的块）；更早版本仍需手动安装
- macOS 暂不支持应用内安装（未公证），继续从官网下载页手动安装
