## 更新内容

### 新增

- 定时任务错过窗口留痕：电脑休眠或应用未运行时漏跑的任务记为「已错过」并说明原因，可手动补跑，不再静默丢失
- 桌面防休眠开关（设置 → 通用 → 桌面行为）：关闭 / 仅执行任务时 / 始终三态，任务跑起来时阻止系统空闲休眠
- 会话置顶：侧边栏新增「已置顶」分区，常用会话固定在顶部
- 计划模式新增 ask_user 提问工具：澄清问题直接在对话里问，支持单选、多选与自定义作答
- 新增 macOS Intel (x64) 安装包（实验性支持，未广泛测试）

### 优化

- 工具定义对模型可见性：插件与懒加载工具的 schema 改为限深保留嵌套形状，模型能看到数组元素与子对象结构，减少参数校验失败与反复重试
- 远端工作区（SSH / NAS）更耐操：安装目录自动回退（`$HOME` 不存在或不可写时）、SFTP 不可用改走 exec 通道上传并校验字节数、端口转发被禁给出可操作提示
- Git 侧边栏变更数改为监听工作树：编辑、新增、删除文件后自动刷新，不再需要手动刷新或重开页面
- 前台子代理超时由 5 分钟延长至 20 分钟，复杂子任务不再频繁转后台

### 修复

- 修复并行工具调用只有第一条显示结果、其余一直停在「执行中」的问题
- 修复工作流子代理永不释放、占满父会话名额后无法再派生子代理的问题
- 修复桥接连接销毁后仍反复重连，导致组件退不掉、进程无法退出的问题
- 修复工具调用配对非法触发上游 400：冷加载、出站请求与压缩边界统一补配对与兜底
- 修复 macOS 沙盒：补随包 Intel 二进制；并修掉 arm64 沙盒要求 macOS 26 导致老系统用不了的问题
