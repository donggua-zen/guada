## 更新内容

### 新增

- **实时同步与断点续传**：会话事件改为单条 WebSocket 按会话订阅，并支持按 seq 增量补拉，配合回合终态墓碑与侧栏修订号对账 —— 切后台、断网重连、多窗口/多端同时在线时自动补齐缺失消息与回合终态，不再停在旧画面
- **流中断自动恢复**：上游断流时按「内容是否收齐」判定并分层处理（完整工具照常执行、残缺工具丢弃留审计、正文截断可自动续写）；设置页新增「流中断恢复」可选自动恢复（最多 10 次）或直接终止报错
- **消息投递时机**：流式运行中发送的消息默认排队，可在排队项上改为「边界引导」（工具批次结束后接管）或「立即」打断；子代理运行中也能接收主代理补充指令，并以可见的协调者消息呈现
- **计划提交 `submit_plan`**：计划工具由 `ExitPlanMode` 更名为 `submit_plan`，普通模式也可提交计划征求批准（批准后仅在计划模式开启时自动退出），历史计划记录同时兼容新旧名称
- **知识库 DeepSeek OCR**：OCR 新增 DeepSeek 供应商，可直接复用「模型服务」里已配置的 DeepSeek Key，识别文本自动剥离 OCR 布局标记后再入库
- **后台作业完成通知**：作业结束后在下一次模型请求边界自动回注输出全文（文本类作业），主代理无需再手动读取；终端/PTY 类作业保留状态与指引，避免重复投递
- **Computer Use 单入口**：`computer_observe` / `computer_a11y_observe` / `computer_input` / `computer_launch` 收敛为 `computer_run` 脚本入口并内置 computer-use 技能，支持逐步策略审批、进程级桌面锁、动作/观察/截图预算，计划模式下只读，并放开 macOS arm64
- **macOS 应用内更新**：macOS 支持在应用内下载 dmg 并原地覆盖安装后自动重启（此前只能跳浏览器手动下载）
- **本地文件链接预览**：Markdown 中的 `file://` 链接可直接在侧栏打开预览，工作区外文件提供「用系统默认程序打开」，并限制可执行/脚本类型

### 优化

- **长会话性能**：对话流改为有界回合窗口（视口外回合卸载为等高占位）+ 折叠组延迟挂载 + 工具卡先截断再高亮，长会话滚动、窗口缩放与大文件展开更流畅；侧栏开合动画复用调整期降级，开关不再卡顿
- **历史记录读取**：会话事件页改用轮次锚点索引定位、按页做字节区间读取（50MB 会话冷启动读取量约从 54.7MB 降到 0.55MB），长会话首次打开与上翻加载明显更快
- **轨迹与工具卡**：统一工具/思考行的配色层级、扫光效果、图标与行距，补齐「正在执行 N 条命令」等聚合标题、完成态改为「已思考」，`run_command` 折叠标题显示模型给出的语义描述，子代理行头像与文字左缘对齐，中文状态文案精简，压缩提示改为静态胶囊
- **Markdown 排版**：统一块间距与 1.75 行高，代码块改卡片式并换用 GitHub 明暗高亮色板，表格、列表、引用与行内码观感重做
- **主题与视觉细节**：暗色主色与正文提亮、侧栏层次调整、完全访问权限档位改警示橙、表单控件统一白底灰边、字体渲染与侧栏英文粗细优化、次要文本与待办卡配色统一设计令牌
- **输入区状态胶囊**：后台任务改为两行卡片并按进程/子代理分段、子代理使用专属头像，浏览器窗口入口从概览面板迁入胶囊（新建仍走工作区起始页），移动端改为点击展开并支持点外部/Esc 收起

### 修复

- 修复移动端后台唤醒后打开会话提示「加载消息失败」且刷新无效 —— 2xx 空响应或非 JSON 响应现在显式报错并自动重试，接口响应禁用缓存
- 修复上游断流时仍执行被截断的半截工具（如残缺的写文件参数）导致报错或重复副作用，残缺工具改为跳过并保留审计
- 修复完整回答因上游省略结束事件被误判为断流，以及断流错误残留到后续成功回合、回合结束仍报 `network_error` 的问题
- 修复 Responses 协议思考与正文顺序颠倒（正文跑到思考前面），以及纯空白块渲染出「已思考」空行/空卡片的问题
- 修复 Responses 工具参数只收到增量、缺少 `done` / `output_item.done` 载体时参数不完整的问题
- 修复进行中工具分组标题的状态文案被 i18n 吞掉、标题恒为「已执行 N 个步骤，」的问题
- 修复从设置页/插件页返回后浏览器标签偶发不出现、需切换一次会话才恢复的问题
- 修复文件预览不支持绝对路径（工作区外文件被拼错路径并 403），以及「在文件夹中显示」对不存在路径静默无反应的问题
- 修复 grep 的 `max_results` 超过 50 直接报错的问题，改为运行时截断到 200 并提示仍有更多结果
- 修复全局技能管理页列出智能体专属技能、以及 `enabled-status` 接口返回空响应体导致技能启停状态异常的问题
- 修复远程工作区大文件传输中途断链会带走整个后端进程的问题，断链改为安全关闭传输并给出进度提示，下次调用自动重连
- 修复桌宠按住后拖不动的问题（鼠标转发失效导致窗口持续穿透、按下事件进不来），并补齐 NOACTIVATE 窗口的假失焦处理

### 说明

- 实时通道从 SSE 改为 WebSocket（`/api/v1/events/ws`，子协议 `guada.events.v1`，Bearer 鉴权）；自建反向代理需放行该路径的 WebSocket Upgrade（官方 nginx / docker 配置已带 Upgrade 头，通常无需改动）
- macOS 从 1.0.13 起支持应用内下载并原地覆盖安装；**1.0.12 及更早的 macOS 用户仍需手动安装一次**才能获得该能力
- Computer Use 四个旧工具名已退役，旧名调用会返回「改用 `computer_run`」的提示；自定义提示词、技能或插件中硬编码旧名的建议同步更新。计划工具 `ExitPlanMode` 更名为 `submit_plan`，历史记录与前端渲染双名兼容
- 远程工作区新增 `REMOTE_TRANSFER_MAX_MB`（默认 4096）与 `REMOTE_FILE_MAX_MB`（默认 64）闸门，超限在入口直接拒绝并给出可执行提示
- 流中断默认恢复次数由固定 5 次提升为 10 次，可在设置页改为「直接终止并报错」
- 计算机 sidecar 更新到 v0.2.0（仅 darwin-arm64 哈希变化，Windows 侧不变，`sidecar.lock.json` 已同步）
- 本版暂仅提供 GitHub 构建产物；官网下载页与 GitCode 镜像将在官网改版完成后同步
