## 更新内容

> 本版包含 **1.0.11 的全部内容**（1.0.11 未走官网分发，仅 GitHub Release 存档，从 1.0.10 可直接差量升级到 1.0.12）。

### 新增

- **历史会话导入**：支持从 Claude Code、ZCode、DSH、Codex、WorkBuddy 迁移历史会话 —— 自动扫描本机数据、按时间/工作区筛选、按工作区分组多选导入；保留原始时间戳与上下文占用锚点，重复导入幂等跳过（WorkBuddy 为第五来源，双根扫描、提取真实提问、配对工具调用结果、去重编辑重发与映射用量）
- **去 Element Plus 收官**：全部 UI 控件迁移到自研 Gd 组件，element-plus 整包卸载；顺带修复一批组件层缺陷（下拉"无数据"、滑块不跟手、开关无效、弹窗滚动等）
- **供应商体系插件化（Provider Pack）**：外部供应商可通过安装插件包接入，无需改应用代码；协议下拉/标签/图标全部接口驱动；新增 Ollama 原生协议示例包。行为变更：未知协议不再静默回退 openai，改为明确报错
- **请求体 gzip 压缩**：≥64KB 的 JSON 请求体自动压缩（任何协议可用，供应商卡片或实例声明 `requestCompression` 即可），编码被拒自动明文重发；实测 288KB 请求压到 1.7KB
- **在线插件市场与宠物市场**：插件页新增「市场」视图（官网索引 + git 托管分发，搜索、标签、分页、详情、带进度的安装）；安装框自动识别仓库网页地址、clone 地址、`owner/repo` 短写法、`file://` 与本地路径；设置页新增「宠物市场」（索引、缩略图、一键安装，直接下载精灵图，不依赖 Node/npx）
- **插件 API v3/v4 运行时**：新增自定义 HTTP 路由、宿主模型调用（complete/stream/listModels）、后台作业、Hook、命名提示词段与装配变换、插件数据目录、配置 Schema 表单；前端新增可完整卸载还原的主题/皮肤运行时、全页工作台与对话侧栏页槽、插件通用配置页
- **插件专属智能体与能力包**：插件可注册虚拟智能体（能力作用域、部分字段可编辑、子代理白名单与 hidden 角色），工具包升级为能力包（注册技能并随全局启停/角色裁剪/加载模式同步显隐）
- **模型调用轨迹台账**：工作区新增「调用轨迹」面板，以会话 JSONL 事件流为唯一事实源（JSONL 即轨迹）拉式投影模型调用全链路——Request 边界行、SYSTEM 快照默认可见、工具/消息卡片逐块展开与复制；审计化后全量事件流可见（删除轮次亦可见），并收敛 token 字段（usage 以 assistant 消息 metadata 为唯一载体、上下文占用锚点统一归 context/stats）
- **Computer Use 支持 macOS**：新增 Swift sidecar（darwin-arm64）随包分发，截图、窗口列表、AX 无障碍树、点击/输入/滚动、启动应用等工具与 Windows 全面对齐（快捷键自动映射 ctrl/cmd→Command、alt→Option），新增 Apple 事件权限文案与「系统设置 → 隐私与安全性」直达入口
- **桌宠拖拽与穿透稳定性改造**：拖动协议由增量改为「按下点 + 当前点」绝对屏幕坐标（旧增量方案在窗口随光标 1:1 移动时 Chromium 不再发 pointermove，拖一下就断流）；穿透保持 `setIgnoreMouseEvents` 并在锁屏/熄屏/重新显示后自动重新武装转发；熄屏/锁屏唤醒后指针捕获残留与交互态卡死全面自愈（按下心跳保活、连续多次 `buttons==0` 才判松手、窗口表面失效时无缝重建兜底），配套真实鼠标注入的端到端回归测试
- **桌宠右键调试菜单**：开 DevTools / 复制诊断信息 / 抓取渲染层拖拽状态 / 无缝重建窗口，便于自助排查「拖不动」类问题
- **工作流阶段站条**：工作流运行卡新增横向站条投影，按 phases 声明把成员步骤归组到各阶段站（固定站宽、横向滚动、镜头跟随），并适配窄面板与移动端（分页翻站箭头、自绘横向滚动条、两侧渐隐遮罩）
- **子代理行身份与即时终态**：每个子代理分配稳定身份色的卡通头像脸（运行时眨眼/左右看动画），完成绿勾、失败红叉用「形状+颜色」双通道表达，终态按工具调用即时回传到行内，不再等整批汇总刷新
- **会话目标自动推进**：`/goal` 设置/暂停/恢复/清除目标，输入区状态胶囊显示阶段、迭代数与用量，独立 verifier 判定推进，状态以 JSONL 事件溯源落盘（零数据库改动）
- **压缩失败可见化**：上下文压缩失败按限流、网络、超时、请求拒绝分类落库，并在对话流以事件卡展示原因（刷新后仍在，历史消息保持不变）
- **知识库文件预览**：预览弹窗默认「原文预览」（PDF 走 Chromium 原生渲染，图片、Markdown、文本分类型展示），「分块」作为调参核对第二入口并支持复制、检索结果直达命中块
- **Computer Use 工具升级**：`computer_observe` 拆为独立工具并返回 generation，`computer_input` 新增 set_value、drag、click_element 且强制 `expected_generation` 校验，避免基于过期屏幕坐标误操作
- **浏览器标签预算与清理提醒**：每个来源最多 8 个 AI 标签（6 个起提醒、超限返回 `TAB_LIMIT`），新建/关闭结果附带标签摘要、失效标签自动接管、脚本结束列出残留标签
- **任务栏未读角标**：审批/询问到达且窗口隐藏或非当前会话时显示红点（Windows overlay 图标 / macOS Dock badge），进入会话或窗口恢复即清除
- **Shell 后端选择**：新增 `system.shellBackend` 设置（auto / Git Bash / PowerShell / cmd），run_command 与交互终端共用，Windows 按可用性置灰未安装项（默认 auto 行为同旧版，重启生效）
- **其他**：主题新增「柒·义体夜航」与外置皮肤「柒·残月都市」（亮暗通用），移动端主题隔离；文件类工具行文件名可点击、直接在工作区侧边栏打开预览；会话「…」菜单宽窄对话模式切换（744↔1138px）；用量统计新增「今日」维度；输入框默认高度提至 110px

### 优化

- 拖拽分割条/缩放窗口的性能优化：调整期跳过视口外回合绘制、冻结回合高度、合并 rAF 与防抖（300 回合拖拽约 32fps → 60fps），并消除按压不动时的内容塌陷、滚动条跳动
- 流式 Markdown 渲染改为顶层块级缓存 + 150ms 节流（leading 立即、trailing 必达），只重渲尾部变化块
- 拖拽工作区分割条时浏览器预览网页实时跟随（此前手势期间停止测量，网页停在旧尺寸，松手才跳变）
- 输入区运行时状态胶囊整合：后台进程与子代理合并为统一「后台任务」段，后台子代理可在悬停面板内直接终止
- 工具行文件参数改为「扩展名图标 + 文件名 + 淡色目录」三段式，长路径不再挤出文件名
- `job_read` 改为按游标增量读取，未读超上限时只保留最新 64KB 并告知跳过量与完整日志路径
- 计划模式优先委派只读调研子代理；流式生成中允许按已完成回合分支

### 修复

- 修复 OpenAI 兼容供应商流式响应统计不到 token——`include_usage` 尾块（`choices` 为空）此前被直接跳过，现先读 usage 再判 choice
- 修复 LLM 流中途空闲超时被 SDK 吞成正常结束、半截消息（含 tool-call）按成功落库；统一抛超时错误并走既有重试/告警链路（覆盖 openai / openai-response / anthropic / gemini 适配器）
- 修复浏览器自动化输入抢占宿主窗口焦点——AI 点击/打字不再顶掉用户正在输入的输入框，fill 改为页面内写入并回读校验
- 修复插件禁用后其技能仍出现在技能页与 `/` 命令面板的问题，且插件启停后两处即时刷新
- 修复发送失败（网络/4xx/5xx、模型缺失、本地命令被拒）时正文与附件被提前清空；改为服务端确认成功后才清空并聚焦
- 修复思考模型生成提交信息时固定 300 token 预算被思维链耗尽、正文为空误报「生成失败」；移除固定上限，输出截断单独返回 `output_truncated` 并给出中英文提示
- 修复图片预览常驻挂载吞掉全局左右方向键、右侧工作区 Markdown 预览文件变更后滚动位置跳回顶部
- 修复侧栏目录模式新建会话先落「通用」需刷新才归组，以及「通用」桶「+」误落到上次工作目录的问题
- 修复内置主题与深色主题的一批对比度/配色问题（winxp / e-ink / y2k / famicom 接通 token 链、选中行白底白字、写死颜色导致的深浅色不一致、主题 CSS 异步加载后标题栏配色未重算）
- 修复模型编辑页复选框点不动、智能体头像控件贴卡片右缘、运行模式弹层图标变形，以及 Windows 下对话标题栏重复充当窗口拖拽区
- 修复远程工作区连接重名只报 500 且无字段提示，改为名称框字段级提示 + HTTP 409 并回跳聚焦
- 修复 Windows 打包版退出兜底 `taskkill` 缺 `windowsHide` 闪黑色控制台窗口、Electron 脚本异常弹窗阻塞、console 断管后 EPIPE 自激循环刷满日志
- 修复桌宠「柒」形象 idle 第 19 帧素材瑕疵
- 修复 Electron 打包校验：better-sqlite3 若被换回系统 Node ABI 的预编译包，构建时立即检测并重新拉取 Electron 版本，避免本地打包版启动即崩

### 说明

- 桌宠为独立设置项且默认关闭，旧版「托盘悬浮窗」的开关/透明度设置会自动迁移；移除消息「编辑内容」就地编辑入口（链路已失效、后续重新设计）
- 插件 manifest 新增 `apiVersion` 门控（宿主最高 v4，未声明的旧插件按 v1 照常加载）；安装目录统一按 `manifest.id` 命名，旧目录在更新时自动归位
- 浏览器自动化新增标签预算后，一次运行中打开过多标签的既有脚本会收到 `TAB_LIMIT`，需按提示关闭/接管标签
- **macOS Computer Use** 首次授权需在「系统设置 → 隐私与安全性」允许 Apple 事件控制；mac 包新增 sidecar 产物与权限文案，体积略增
- Windows 包产物与 1.0.10 完全一致的部分不受影响，**1.0.10 的 Windows 用户可直接在应用内差量更新到 1.0.12**；更早版本仍需手动安装
- macOS 暂不支持应用内安装（未公证），继续从官网下载页手动安装
