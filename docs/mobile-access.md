# 移动访问（局域网 / 公网 SSH 隧道）

移动访问让手机、平板等设备通过浏览器远程控制本机 GuaDa（对话、文件、终端等）。
入口在 **设置 → 移动访问**，以及侧边栏用户中心旁的手机图标（远程控制弹窗）。

## 安全前提（强制）

- 开启局域网或公网访问前，**必须先设置访问密码**（设置 → 安全设置）。
- 未设密码时开启会被后端拒绝；已开启时**禁止取消密码**（需先关闭移动访问）。
- 应用启动时还会兜底检查：若配置文件为开启状态但账户无密码，会自动关闭全部入口并提示。
- 外部设备通过密码登录，登录后拥有与桌面端相同的权限（包括终端与文件操作），
  请仅在可信网络/服务器上开启。

### 密码强度策略

- **所有密码**：至少 8 位，且包含「字母 / 数字 / 符号」中的至少 2 类；常见弱密码
  （如 `password123`、`12345678`）与包含用户名的密码会被拒绝。
- **公网访问开启期间**：设置或修改密码还要求至少 12 位、字母/数字/符号三类齐全。
  该强度检查只在设置/修改密码时用明文校验一次。
- 密码校验大小写不敏感，因此大写字母不额外增加强度，策略按三类字符计算。
- 不保存强度快照，也不会在开启入口或启动时对存量密码做二次判断——避免状态陈旧
  导致「改了密码仍被拦截」。旧密码是否够强由用户自行判断，公网开启后的任何密码
  修改都必须满足高强度。

## 局域网访问

1. 设置 → 移动访问 → 打开「允许局域网设备访问」。
2. **重启应用**（设置页提供「立即重启应用」按钮）——监听地址在进程启动时决定。
3. 手机连接同一个 Wi-Fi，打开设置页展示的地址，例如 `http://192.168.1.10:3000/`。

说明：

- Linux/macOS 需放行防火墙对应端口；Windows 首次监听时可能弹出防火墙授权，请允许
  （仅专用/私有网络需要）。
- **开发模式（Vite）**：局域网与公网入口都直接指向 Vite dev server 的 `5173`，
  手机端享受热重载，无需先构建前端；设置页/弹窗展示的地址就是 `http://<IP>:5173/`。
  需要 `pnpm dev` 正在运行（Vite 已配置 `host: true` 与 `allowedHosts: true`）。
- **生产模式**：由后端 serve 编译产物，入口为后端当次端口（随机），请以设置页/
  弹窗展示的地址为准。
- 前端页面由后端直接 serve（生产）或 Vite（开发）；深链接刷新在生产模式下已通过
  注入 `<base href="/">` 处理。

## 公网访问（SSH 反向隧道）

本机主动连接你自己的公网服务器，建立 `ssh -R` 反向隧道，无需公网 IP、路由器端口
转发或 DDNS。服务器只需运行 sshd。

### 服务器准备

1. 确认 sshd 允许 TCP 转发（默认 `AllowTcpForwarding yes`）。
2. 若「远端监听地址」选择 `0.0.0.0`（公网直接访问端口），sshd 需配置
   `GatewayPorts yes`（或 `clientspecified`），并在服务器防火墙放行该端口。
   若选择 `127.0.0.1`（推荐），请在该服务器上用 nginx 等反向代理到
   `127.0.0.1:<远端端口>`，由代理负责 HTTPS/域名。
3. 为 GuaDa 准备一个 SSH 账户，使用私钥或密码认证。

### 客户端配置

设置 → 移动访问 → 公网访问：

| 字段 | 说明 |
| --- | --- |
| 服务器地址 | 公网 IP 或域名 |
| SSH 端口 | 默认 22 |
| 用户名 | 服务器 SSH 账户 |
| 认证方式 | 私钥文件（推荐）或密码（AES-256-GCM 加密落盘） |
| 远端监听地址 | `127.0.0.1`（配合服务器反代）或 `0.0.0.0`（需 GatewayPorts） |
| 远端端口 | 服务器上映射的端口，默认 8787 |
| 自定义公网地址 | 可选；如 `https://guada.example.com`，留空则按「服务器地址:远端端口」推导 |

保存后隧道即时启停/重连，无需重启应用。设置页与弹窗会显示连接状态和最近错误：

> 隧道转发目标：生产模式为后端端口（编译产物），开发模式下为 Vite dev server
> 的 `127.0.0.1:5173`（热重载）。

- **已连接**：隧道建立成功，可扫码访问。
- **连接中**：正在握手/重连（断线自动指数退避重连，1s → 30s）。
- **连接失败**：常见原因包括服务器拒绝转发（`administratively prohibited`，检查
  GatewayPorts/AllowTcpForwarding）、私钥不可读、密码错误、端口被占用。

### 主机指纹（TOFU）

首次连接会记录服务器主机指纹，此后指纹变化将**拒绝连接**（防止中间人或服务器被
替换）。确认服务器确实重装/换机后，可在设置页「清除指纹」后重新连接。

## 已知限制

- 公网地址仅支持**根路径**部署；如通过 nginx 子路径转发，需自行改写资源路径。
- 尚未实现登录限速/防爆破；公网暴露时建议在服务器侧加 nginx 限流或仅开放可信来源。
- 多网卡（含虚拟网卡）会展示多个局域网地址，请选择手机实际可达的那个。
