# 安全模式三档方案（对齐 DSH SandboxMode）

> 版本：1.0 | 日期：2026-08-29 | 状态：已实施
> 前置：本文取代旧五值 `SessionRunMode`（normal/sandbox/memory/plan/free）。

## 1. 词表：三档，与 DSH `SandboxMode` 同构

| 模式 | 语义 | shell（run_command） | 文件工具（write/edit） |
|---|---|---|---|
| `read-only` | 只读 | 经沙盒 `--read-only` 执行，全部写入被拒（命令可运行，写入报错） | 直接拒绝，提示走提权或让用户切换模式 |
| `workspace-write`（默认） | 工作区可写 | 经沙盒执行，仅工作目录内可写 | 工作区路径包含校验 |
| `danger-full-access` | 自由编辑 | 不启用沙盒 | 不限制工作目录，可写任意路径（UI 红色警示） |

- 词表只约束**文件效应**；网络与进程可见性不在词表内（对齐 DSH："governs filesystem effects only"）。
- 默认值 `workspace-write`：新会话与未知持久化值均回退到该档。
- 持久化：`session.settings.sandboxMode`；子代理创建时从父会话继承（防权限逃逸）。
- 模式切换叙事：用户消息 `metadata.sandboxMode` 记录当轮模式；`detectModeTransition` 比对
  上一条 user 消息，进入/退出 `read-only` 与进入/退出 `danger-full-access` 的叙事可叠加写入
  `metadata.systemReminder`。

## 2. 提权（one-shot escalation）

- 模型在工具参数带 `sandbox_permissions` + `justification`（成对，理由非空）。
- `assertStrictlyWider` 严格放宽阶梯：`read-only → workspace-write/danger-full-access`，
  `workspace-write → danger-full-access`；平级/降级直接抛错，不打扰人。
- 审批走统一 Ask（`AskService.requestApproval`：同意 / 拒绝 / 自定义回复，无超时）；
  批准后仅本次调用按批准模式放行（one-shot）。
- `danger-full-access` 下提权参数无意义：shell 直接报错 unavailable，file 直接报错 unnecessary。

## 3. 工具范围锁定（原 memory 模式）

影子轮次（记忆同步）需要"仅 memory 插件工具"的瞬态约束——这是**工具可见性**，不是安全档位，
故与安全模式分离为 `ISessionContext.setToolScope(pluginId | null) / getToolScope()`（不入库）：

- `MemorySyncService.runShadowTurn` 进入时 `setToolScope("memory")`，finally 恢复原值；
- `ToolExecutorService.executeTool` 对锁定范围外的工具返回 isError。

## 4. 与 DSH 的对照

- DSH 词表同样是三档（`read-only` / `workspace-write` / `danger-full-access`），
  默认 `read-only`（fail-safe）；本项目默认取 `workspace-write`（工作区型助手的中档体验）。
- DSH 的 plan mode 是**正交的软引导协作状态**（prompt section + exit_plan_mode 工具），
  不读写沙盒与审批状态；本项目原 plan 把"协作状态"与"强制只读"耦合，属不规范来源，已移除。
- DSH 模式切换 = 追加 `sandbox/mode` log 事件（last-wins fold、replay 即状态、天然审计）；
  本项目暂存于可变 settings，后续如需审计轨迹可升级为同类 log 事件。

## 5. DSH 只读模式与命令行（问题确认）

- **只读可以调用命令行**：`read-only` 只约束文件效应，命令照常执行；被拒写入以
  `sandbox.denied: true` 作为结果事实回报，并附提权引导（denial 是结果，不是工具不可用）。
- **终端实现**：DSH 沙盒执行器有两套镜像实现，按部署挂载——
  POSIX 用 `dsh-bash-sandbox`（`bash -c <command>`，配 bwrap/Landlock/Seatbelt 后端）；
  Windows 用 `dsh-pwsh-sandbox`（`pwsh -NoLogo -NoProfile -NonInteractive -Command`，
  配 ACL restricted-token 后端）。工具 schema、结果分类、提权字段完全对偶。
- 本项目对应物是自带 `sandbox.exe`（`--workspace cwd` + 可选 `--read-only`），
  二进制缺失时 fail-closed 报错，不静默放行。
